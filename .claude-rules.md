## 11. ONE BUILTIN TABLE

`aurora-abi` is the single source of truth for every builtin's name, signature and
symbol, and it is depended on by both codegen and the runtime precisely so a builtin
cannot exist on one side only. A builtin that is documented must exist and one that
exists must be documented (`documentation_debt_only_shrinks`, against
`docs/04-stdlib-and-builtins.md`). Never a second list of builtin names beside the
table - `aurora-codegen` held one, and a builtin that was a row in the table could not
be found by the compiler.

## 12. THE GATE, EXACTLY

    cargo fmt --check
    cargo test --workspace --profile release-test -j 4

`release-test`, not `release`: `--release` took ninety-plus minutes, almost all of it
LTO linking once per test binary, and a ninety-minute gate is a gate that stops being
run. Not debug either - suites drive a real GPU and real sockets. `-j 4` is part of the
recipe, not a laptop concession; cargo's default takes the machine with it.

## 13. A CHECK THAT CANNOT RUN MUST BE AS LOUD AS ONE THAT FAILS

The fixture tests used `let Some(m) = fixture(..) else { return };`, so six root-motion
tests and both modular-character tests had never run on the machine Aurora is developed
on, and reported `ok` having asserted nothing - the test COUNT could not reveal it
either. Unset `AURORA_TEST_FBX_DIR` now FAILS. Skipping requires typing
`AURORA_SKIP_FIXTURE_TESTS=1`, and having to type it is the point.

## 14. DEPENDENCIES POINT DOWN

`span`/`diag` at the bottom, then the front end, then codegen, then the runtime and
engine, with `aurorac` on top. Never up. A crate's contract is its `lib.rs` header -
its job, its place in the graph, and what it must never do. There are deliberately no
per-crate READMEs; the header is the one home for that fact.

## 15. AN AGGREGATE IS A VALUE

`let`, `=`, a field, an element and a by-value parameter all COPY. Only `&T`, `&mut T`
and a method's `self` share storage, and both ends say so. A parameter's copy is
unconditional. Eleven tests in `tests/value_semantics.rs` fail on the previous codegen;
they are the contract, not a regression net.

Beside it: an array type's LENGTH must survive every pass that walks types. Three
passes have dropped it, each silently (`tests/const_array_length.rs`).

## 16. `check` COMPILES WHAT `run` COMPILES

The user's source, its dependencies and the prelude, assembled identically by all three
commands in `aurorac`. A call to a missing function used to pass `check` and fail `run`;
that is the class of bug this invariant exists to make unspeakable.
